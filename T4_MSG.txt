Add FHSA (First Home Savings Account), accumulation-only (track 4 of #119)

Model the FHSA end-to-end, following the RDSP template:

- Engine: FhsaInputs { enabled, balance, contribution, contributionBasis?,
  openAge? }; deductible contribution capped at the annual ($8k, indexed) and
  lifetime ($40k) limits, contributions stop after the 15-year plan window;
  tax-sheltered growth; the contribution reduces the year's taxable income
  (like an RRSP). At the retirement boundary the balance transfers to the
  RRSP (CRA allows the direct transfer with no contribution room), so capToRoom
  is bypassed. The FHSA never enters the decumulation withdrawal order.
- Config: FhsaConfig { annualLimit, lifetimeLimit, maxYears } = 8000/40000/15
  with defaults + all-or-nothing back-fill; SettingsModal FHSA section.
- Schemas: fhsaSchema; wired into RetirementInputs, SpouseInputs and appConfig.
- Sidebar: primary FHSA section (enable/balance/contribution/contributed-to-
  date/age-opened) + spouse FHSA inputs.
- Tables/exports: ScheduleTable + PrintSummary FHSA balance column (shown only
  when present) + detail panel section; projectionExport FHSA column group.
- Assistant: propose_fhsa tool + FHSA in the read-context snapshot; 'fhsa'
  added to the structural-field guard.
- Help: FHSA entry (deductible, sheltered, 15-yr window, RRSP transfer;
  first-home withdrawal not modelled).
- householdTypes: PersonInputs.fhsa + legacy converters thread it through.

Opt-in and defaults off, so the golden master is unchanged. 8 new Vitest
cases (accumulation, annual/lifetime caps, 15-yr window, sheltered growth,
boundary transfer, deduction, disabled). 878 tests green; npx tsc -b clean;
npm run build ok.
